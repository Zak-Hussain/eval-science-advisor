# ai-psychometrician
Your AI safety psychometrician 

### Advantages of the AI psychometrician

1. **Data sensitivity.** It can run entirely on your own server with an open-weights model, so dangerous-capability items, held-out test sets and confidential client evals never leave your environment.
2. **Validated performance.** Its judgements are benchmarked against expert reviewers, with published agreement rates and known error rates. A prompt has no track record; a validated instrument does.
3. **Cross-benchmark context.** It accumulates reference data across many evals and models, so it can tell you things no prompt can see from your eval alone, such as "this overlaps heavily with HarmBench" or "these items are too easy for current frontier models." This improves with use.
4. **AI-specific psychometric know-how.** It knows which analyses fit an AI eval and how to adapt them: few models but many items, regularization, judge reliability, sign-flipped composites. Human-testing defaults misfire here.
5. **Reproducibility and an audit trail.** Versioned principles and consistent reports, with every finding traceable to evidence and sources. It's suitable for regulators, clients and release decisions, where an ad hoc chat isn't.
6. **Standards and regulatory mapping.** It reports findings against frameworks like NIST AI 800-2, AEF-1 and the EU Code of Practice, which is Illuminate's core expertise.
7. **Workflow integration.** It reads Inspect logs, re-runs on each revision and tracks an eval's quality over time.
8. **Gets better as models improve.** It's model-agnostic, so each new open-weights or frontier model improves the tool rather than competing with it.
